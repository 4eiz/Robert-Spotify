# Robert Spotify

Личный кабинет учёта Spotify Family и VPN. Next.js + TypeScript + Lucide; Django REST Framework; PostgreSQL в Docker. Локальная версия использует SQLite, чтобы проверять приложение без запущенного Docker.

## Локальный запуск (Windows)

```powershell
cd path\to\family-ledger
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

Открой http://localhost:3000 и нажми «Открыть локальную версию». Серверы слушают только loopback. Локальный вход включён лишь при DEBUG=1 и LOCAL_DEV_LOGIN=1; в Compose оба флага принудительно выключены.

Инициализация пустой базы с вымышленными данными (необязательно):

```powershell
.\.venv\Scripts\python.exe backend\manage.py seed_demo
```

Команда откажется работать с непустой базой. Чтобы начать с пустой базы, останови backend, сохрани резервную копию backend/local.sqlite3 и перемести этот файл из проекта, затем выполни migrate. Не делай этого после ввода реальных данных без резервной копии.

## Правила учёта

- Для давнего участника дата присоединения и уже оплаченный срок указываются отдельно. Действие «Учесть прежнюю оплату» продлевает срок и сохраняет комментарий в истории, без нового поступления денег и изменения срока семьи. Оно не позволяет сокращать уже оплаченный период. Для нового поступления используйте «Добавить оплату».

- Семья: максимум 6 активных участников, включая одного владельца. Бесплатный владелец не подразумевается автоматически — это отдельный флаг.
- У участника собственные сроки Spotify и VPN, независимые от оплаченного срока семьи. Новая оплата начинается от самой поздней даты: текущий оплаченный срок, дата поступления, дата вступления. Конец периода — исключительная граница: месяц с 15 октября действует до 15 ноября. 31 января + месяц = последний день февраля. Оплачивать можно 1–120 календарных месяцев.
- Spotify и VPN оплачиваются отдельными записями. Сумма предлагается по тарифу, но вводится вручную в BYN. Бесплатное участие не создаёт задолженность.
- Запись оплаты фиксирует семью, реквизиты и курсы на тот момент. Перенос не изменяет прошлые платежи. Для переноса нужны новая семья и новая почта; старый пароль очищается. Владельца нужно сначала снять с этой роли.
- Удаление участника — архивирование. Платежи и история сохраняются. Семью можно архивировать после освобождения мест.
- Себестоимость в карточках — сумма за указанное количество месяцев. Прогноз делит её на месяцы. Смена цены влияет на прогноз, прошлые записи не пересчитываются.
- «Продление» принимает количество календарных месяцев (1–120): новый срок рассчитывает сервер от более поздней даты — текущего срока или даты расхода. Добавляется фактический расход. В форме заранее показаны дата и предложенная сумма; сумму можно изменить. Простое редактирование срока исправляет данные без создания расхода.
- Прогноз месячной прибыли = тарифы всех платных активных участников − месячная себестоимость Spotify и доля VPN. Бесплатные пользователи участвуют в распределении себестоимости VPN.
- VPN-расход распределяется между привязанными семьями пропорционально числу их пользователей VPN. Расход без таких пользователей остаётся нераспределённым, это явно отмечается на странице VPN. Исторические доли фиксируются при продлении.
- Денежный поток за всё время = фактические поступления − записанные расходы; это не признанная помесячная бухгалтерская прибыль. Для валютных отчётов используются сохранённые курсы. Если нужного курса на момент записи не было, показывается «—».

## Myfin

Загружаются официальные курсы НБРБ, опубликованные в https://myfin.by/converter (USD и RUB, нормализованные к одной единице валюты). Источник и время загрузки видны в настройках. Обновление — кнопкой; устаревшие данные помечаются после 36 часов. Если Myfin недоступен или изменил формат, прежние данные сохраняются и показывается ошибка. Есть явно помеченный ручной ввод. Это адаптер страницы, а не гарантированный публичный API Myfin.

## Telegram Login

Используется официальный OIDC Authorization Code + PKCE: https://core.telegram.org/bots/telegram-login. Никакого входа через команду боту. Telegram требует зарегистрировать приложение через BotFather и получить Client ID/Secret. Разреши callback URL в настройках приложения.

В .env укажи OWNER_TELEGRAM_ID (числовой sub/ID своего аккаунта), TELEGRAM_CLIENT_ID, TELEGRAM_CLIENT_SECRET, TELEGRAM_REDIRECT_URI. Backend проверяет подпись RS256 через JWKS, issuer, audience, expiry, nonce, state и точное совпадение ID владельца. Другие аккаунты не получают доступ. Реальный вход требует твоих ключей и регистрации URL; в текущем экземпляре он не настроен и не проверялся с живым аккаунтом.

## Напоминания в Telegram

В .env укажи TELEGRAM_NOTIFICATION_TOKEN и OWNER_TELEGRAM_ID. Открой бота и отправь ему /start. Запусти:

```powershell
.\.venv\Scripts\python.exe backend\manage.py send_reminders
```

Фоновый процесс проверяет события раз в минуту. Не более одной сводки в день после 09:00 Europe/Minsk: семьи, VPS/прокси и оплаты участников за ближайшие 7 дней и просрочки. При ошибке Telegram повторяет попытку, не отмечая сообщение отправленным. Пароли и реквизиты в сообщения не включаются. В Docker worker работает отдельным сервисом. В локальном запуске процесс не стартует автоматически, пока не настроен бот. Реальная доставка без твоего токена не проверена.

## Docker / PostgreSQL

1. Скопируй .env.example в .env на сервере, задай секреты (не копируй локальный режим). Для FIELD_ENCRYPTION_KEY: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. Для Django — случайная строка минимум 50 символов. Пароль PostgreSQL должен быть безопасен для URL либо URL следует правильно закодировать.
2. Укажи домен в ALLOWED_HOSTS (без схемы); HTTPS origin в CSRF_TRUSTED_ORIGINS, FRONTEND_URL; полный callback в TELEGRAM_REDIRECT_URI. Настрой Telegram и уведомления.
3. `docker compose up -d --build`. Миграции выполняются отдельным одноразовым сервисом перед API и worker. Новая PostgreSQL база пуста; демо не создаётся автоматически. SQLite не переносится автоматически.
4. Направь существующий HTTPS reverse proxy на 127.0.0.1:3000. PostgreSQL и API не публикуются наружу. Существующий сайт не изменялся. Порт можно заменить, если занят.

Перед развёртыванием проверьте весь стек на PostgreSQL, официальный Telegram Login и доставку уведомлений.

## Секреты и резервные копии

Пароли аккаунтов зашифрованы Fernet в базе и не выдаются списочными API. Раскрытие доступно владельцу отдельным POST и записывается в журнал. .env, ключ шифрования и дампы не входят в Git. Сохраняй резервную копию базы **вместе с отдельной защищённой копией FIELD_ENCRYPTION_KEY**: без ключа пароли не восстановить. Не заменяй ключ на существующей базе без миграции зашифрованных данных.

## Проверки

```powershell
.\.venv\Scripts\python.exe backend\manage.py test ledger
cd frontend
npm run typecheck
npm run build
npm run test:ui
npm run test:paid-periods
# При запущенной standalone-сборке на loopback:3001:
node tests/security.mjs
```

Браузерные проверки рассчитаны на локальные серверы с демонстрационными данными, используют установленный Chrome и не вводят реальные пароли. Дизайн и палитра: DESIGN.md.

В карточке владельца пароль показывается в поле и копируется отдельной кнопкой без диалога. Раскрытое значение скрывается через 30 секунд, при потере фокуса окна или скрытии вкладки. Цены участника зависят от флагов VPN и бесплатного участия. Второй владелец блокируется формой, API и ограничением БД.

Результаты проверки защиты и ограничения: SECURITY.md.
